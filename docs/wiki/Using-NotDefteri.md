# Using NotDefteri

The interface is in Turkish. Where a menu or button is named, the Turkish label comes first.

## Pages

- **New page:** the pencil button in the title bar adds a page next to the selected one.
- **Right-click a page** in the sidebar to add a sub-page or a sibling, rename, pin (📌) or delete it.
- **Drag pages** in the sidebar to reorder or nest them.
- A new page is named after its first line, and the name follows that line as you edit it.

## Formatting as you type

- **Select text** to get the formatting bar: bold, italic, strikethrough, code, highlight, link.
- **Type `/` at the start of a line** for the block menu: headings, bulleted and numbered lists,
  to-do, quote, code block, divider, sub-page, image and coloured callouts. Type to filter,
  press `Enter` to pick.
- **Markdown works too:** `# `, `- `, `1. `, `- [ ] `, `> ` and ` ``` `.
- **Leaving a code block:** press `Enter` three times on empty lines at its end.
- **Sidebar buttons:** **B1 / B2 / B3 / Aa** set the heading level; **A− / A+** change the size of the selection.

## Linking pages

Type `[[` to get page suggestions. Picking one inserts `[[Page name]]`, and clicking it opens
the page. A link to a page that does not exist yet offers to create it. Links update when a
page is moved or renamed.

## Images

Paste or drag an image into a page. The file is copied into that page's `Görseller/` folder.
Drag the image's corner to resize it.

## To-dos

Lines that start with `- [ ]` are check boxes. Click the box to check a task off.

## Home page

Open it with **🏠 Ana Sayfa** in the sidebar or `⇧⌘H` / `Ctrl+Shift+H`. It shows:

- a greeting, today's date and a live clock;
- **recently opened pages** as cards;
- **quick actions:** new page, daily note, new page from a template.

On macOS the cards rearrange into more or fewer columns as the window changes width.

## The window (macOS)

- **Double-click** the empty part of the title bar to fill the screen; double-click again to
  return to the previous size and position.
- **Drag the window to a screen edge** to snap it: left or right edge for a half, a corner for a
  quarter, the top edge to fill the screen. A preview shows where it will land.
- Dragging a snapped window away restores its previous size.
- **Full screen:** `⌃⌘F`.

## More

| Feature | How |
|---|---|
| Quick finder | `⌘P` / `Ctrl+P`; ignores Turkish letter differences (“istanbul” finds “İstanbul”) |
| Table of contents | Appears on the right of long pages; click a heading to jump to it |
| Section folding | Fold the content under a heading |
| Autosave | 5 seconds after you stop typing, and when you quit |
| Page history | Restore an earlier version of a page |
| Trash | Deleted pages can be restored for 30 days |
| Export | PDF, web page or plain text |
| Themes | Sepia (default), Greenish Paper, Gray Paper, Terminal |
| Keep on top | The pin button in the title bar |
