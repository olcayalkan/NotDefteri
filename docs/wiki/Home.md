# NotDefteri Wiki

A simple notebook for notes, to-dos and ideas on **macOS** and **Linux**.
Text formats as you type, pages nest in a tree, and every note stays on your
computer as a plain Markdown file.

## At a glance

- **macOS:** AppKit, no third-party packages
- **Linux:** GTK 4 (tested on Ubuntu 22.04)
- **Language:** Swift 5.9, Swift Package Manager
- **Format:** Markdown; one folder with an `index.md` per page
