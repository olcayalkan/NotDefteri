# Ana Sayfa Implementation Plan

> **For agentic workers:** Uygulama bu oturumda doğrudan yapılır; kullanıcı talimatları test, commit ve onay adımlarının yerine geçer.

**Goal:** Açılışta ve ⌘⇧H ile sade, kaydırılabilir Ana Sayfa göster.
**Architecture:** Arama önbelleğine özgün Markdown eklenir. Mantık Cekirdek, AppKit görünümü Gorunum, eylemler NotPenceresi extension'ında kalır.
**Tech Stack:** Swift, saf AppKit, macOS 12+; bağımlılık yok.
**Spec:** Kullanıcının 023 — Paket E isteği.

## Global Constraints

- Test yazma; swift test çalıştırma. Doğrulama: swift build.
- Kullanıcının mevcut değişikliklerini koru; checkout/stash/reset/commit yok.
- Tuş başına belge/sayfa taraması ekleme; mevcut kayıt ve önbellek yollarını kullan.
- Markdown gidiş-dönüş yazılışını koru; yeni sözdizimi ekleme.

## Review Focus

- Kirli açık nottan Ana Sayfa'ya geçişte kayıt hatası geçişi durdurur.
- Aynı açık nota dönüşte editör ve undo korunur.
- Yapılacak satırları kod bloklarından ve frontmatter'dan alınmaz.
- Güncel olmayan yapılacak satırına tıklamak başka satırı değiştirmez.
- Günlük not eski düz dosya düzeninde de tekrar oluşturulmaz.

### Task 1: Önbellek ve veriler

- [x] Arama önbelleğinde ham Markdown tut; yalnızca mevcut yükleme/kayıt yolunda güncelle.
- [x] Cekirdek'te bekleyen yapılacakları ve üç yerleşik Markdown şablonunu hazırla.
- [x] Son açılma tarihini mevcut son açılanlar listesiyle birlikte UserDefaults'ta sakla.

### Task 2: Görünüm ve eylemler

- [x] Gorunum/AnaSayfa.swift: selamlama/tarih, yatay kart bölümleri, gruplu ilk 20 yapılacak, +N daha, hızlı eylemler.
- [x] Pencere/NotPenceresi+AnaSayfa.swift: kayıtla geçiş, satıra gitme, atomik tamamlanma, günlük ve şablon oluşturma.

### Task 3: Bağlantılar ve doğrulama

- [x] Kenar panelin üstüne Ana Sayfa düğmesi; Git menüsü ve ⌘⇧H.
- [x] Varsayılan açık başlangıç tercihi, Görünüm menüsünde aç/kapa; tema ve yerleşim bağlantıları.
- [x] Kod haritasını güncelle; swift build ve diff kontrolü.

Doğrulama kaydı: son düzeltmelerden sonra izin verilen `/tmp` modül önbelleği ile `swift build --disable-sandbox` başarılı (9,11 sn, çıkış 0); `git diff --check` temiz. Kullanıcının talimatıyla test ve commit yapılmadı.

İnceleme: bağımsız kod incelemesindeki açık editör/cache sürüm ayrışması ve Ana Sayfa'dan aynı nota tek tıkla dönüş sorunları düzeltildi. Panelin açık dosya kimliği korunup seçim için `anaSayfaSecili` kullanıldı. Kapak önizlemeleri tüm favori kartları için yüklenir; çok büyük favori listelerindeki maliyet ölçülmedi.
